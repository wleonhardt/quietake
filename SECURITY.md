# Security reports

Use the repository's private vulnerability reporting:
https://github.com/wleonhardt/quietake/security/advisories/new

Do not post vault keys, private media, credentials or exploit details in public
issues. Include affected commit, expected behavior, reproduction using synthetic
data, and impact. This is an independent development project; no response-time
guarantee or bug bounty is offered.

Quietake is pre-release software. Tests and source review do not constitute an
independent security audit. No released version is currently supported for
production use.
