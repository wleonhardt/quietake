# Share bundle, version 1

A `.quietake-share` file carries one or more captures to another person, protected by a passphrase
that belongs to the share only (decision 025, option B). The vault master key, the keyfile and
`.shtr` containers play no part: opening a bundle never gives the recipient anything about the
sender's vault. The format is separate from the `.shtr` container, so the v1 container contract and
its frozen vectors are unchanged.

All integers are big-endian. Primitives are libsodium 1.0.22: `crypto_pwhash` Argon2id13,
`crypto_secretbox_xsalsa20poly1305` for wrapping the share key and
`crypto_secretstream_xchacha20poly1305` for the body.

| Offset | Size | Field |
| --- | --- | --- |
| 0 | 4 | magic `SHSB` |
| 4 | 1 | version = `1` |
| 5 | 1 | reserved = `0` |
| 6 | 4 | `chunkSize`, plaintext bytes per chunk (the app writes 65536) |
| 10 | 4 | Argon2id operations limit (the app writes 3) |
| 14 | 4 | Argon2id memory limit in bytes (the app writes 67108864) |
| 18 | 16 | Argon2id salt |
| 34 | 24 | secretbox nonce |
| 58 | 66 | wrapped share key: secretbox `easy` output (16-byte MAC first) of the 50-byte message `quietake.share.v1`, one NUL byte, then the 32-byte share key |
| 124 | 24 | secretstream header |
| 148 | … | secretstream chunks |

## Keys

- The wrapping key is 32 bytes of Argon2id13 over the passphrase, encoded as UTF-8 exactly as typed,
  with the header salt and limits.
- The share key is 32 random bytes per bundle, never reused. It is the secretstream key.
- The passphrase is generated by the app as six random words (`BackupPassphrase`) and shown once.
  Readers accept any passphrase of 1 to 1024 UTF-8 bytes; the strength of the bundle is the
  strength of the passphrase, because a copy of the file can be guessed against offline.
- A wrong passphrase, a wrong marker or any change to the wrapped key fails authentication before
  any body byte is decrypted.

## Body

The secretstream plaintext is a sequence of entries with no count and no separator:

| Size | Field |
| --- | --- |
| 4 | `nameLength`, 1 to 255 |
| `nameLength` | entry name, UTF-8 |
| 8 | `contentLength` |
| `contentLength` | content bytes |

Entry names are neutral (`photo-01.jpg`, `video-02.mp4`). A name must not be empty, contain `/`, `\`,
NUL or any other control character, or equal `.` or `..`; readers reject a bundle that breaks this
rule and must not use the name as a path without checking it again. Names are unique ignoring case.
Zero entries is valid.

Chunking follows the `.shtr` rule: every chunk except the last has exactly `chunkSize` plaintext bytes
and tag `MESSAGE`; the last has fewer and tag `FINAL`, possibly zero bytes. An entry may span chunks. A
reader that reaches the end of the file without an authenticated `FINAL` chunk, or whose plaintext ends
inside an entry, rejects the bundle as truncated.

Ciphertext length of the body = ⌊n / chunkSize⌋ × (chunkSize + 17) + (n mod chunkSize) + 17.

## Processing budgets

Readers accept `chunkSize` from 1 to 1 MiB, Argon2id operations from 1 to 3 and memory from 8 KiB to
256 MiB, and reject anything else without clamping. A reader must cap the sum of entry lengths it
will extract (the app uses the share limits in `lib/share`), because `contentLength` is untrusted
until the entry has been authenticated through its chunks.

## What a recipient or the network learns

The file reveals that it is a Quietake share, the KDF cost, the total size (which bounds the number
and size of captures) and nothing else. Entry names, counts and sizes inside the stream are
encrypted. The sender's identity, capture times and metadata are not in the file because the app
applies the share pipeline (metadata removal, redaction) before bundling.

## Recipients

Quietake opens a bundle with the passphrase. The Go recovery tool gains a `-share` mode in a later
slice so anyone can open a bundle from the command line. Neither needs the sender's vault.

## Status

Layout approved by the owner on 2026-11-16. The Dart writer and reader are in
`lib/crypto/share_bundle.dart`. Frozen vectors are in `docs/vectors/share.json` (test parameters:
Argon2id ops 1, memory 8192, chunk size 64; the stream header is random, so the vectors are the
bytes the first writer produced and must not be regenerated). Each case lists the passphrase's
entries as hex; the Go `-share` reader must open them.
