Website privacy

This page covers this project website. Quietake is still in development; the app’s final store privacy policy is not published yet.

A small, static website

This site does not include advertising, analytics scripts, cookies, forms, accounts, or external font requests. It does not ask for photos, videos, passcodes, or recovery keys.

Hosting still involves network data

GitHub Pages serves these pages. Hosting and network providers receive connection information such as your IP address when your browser requests a page. See the GitHub privacy statement. If Cloudflare is used to deliver traffic, its privacy policy also applies.

Links and conversations

GitHub links take you to GitHub, where its privacy practices apply. Avoid posting personal media, keys, passcodes, or server credentials in issues or discussions. Security issues can be reported through private vulnerability reporting.

The app’s boundaries

Read the source repository’s privacy boundaries for details about encryption, optional backup, sharing, casting, recovery, and platform limitations. Those technical notes are not a substitute for the final app privacy policy.
